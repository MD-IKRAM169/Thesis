# Project brief — historical research thesis

## Purpose

This repository records a historical exploratory academic study of linguistic features from Twitter content in the context of suicide-related research labels. It is a **research communication artifact**, not a clinically validated product or an assessment tool for real users.

## Methods and tools discussed in source documents

- Review of literature on social-media language and mental-health research.
- Collection of historical Twitter posts described in the working manuscript.
- Text processing, translation, and category extraction with **LIWC**.
- A feature matrix reported as **132 observations and 71 variables**.
- Exploratory statistical feature selection in **R**, using `leaps::regsubsets()`.

## Reported observation

The manuscript highlights the `leisure` category in some feature-subset summaries. This is **not** evidence of causal effects, a validated diagnostic signal, or a generalizable prediction result.

## Skills relevant to job applications

Literature review, research design, text preprocessing, feature engineering, statistical exploration, research writing and data-ethics awareness. The original thesis PDF and presentation are the main academic deliverables; this later README, documentation and tests are a distinct portfolio-maintenance update.

## Limitations

The available documentation does not establish independent predictive performance, prospective validation, clinical applicability or a safe deployment protocol. Raw identifiable social-media data and any credentials are **not** part of this public update.

For details, see [Methodology](METHODOLOGY.md), [Ethics and limitations](ETHICS_AND_LIMITATIONS.md) and [Reproducibility](REPRODUCIBILITY.md).
